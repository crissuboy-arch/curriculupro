# Guia de Uso - CV Remix PRO

## Importar Curriculo

1. Arraste ou clique para selecionar PDF, DOCX ou TXT
2. A IA extrai automaticamente todos os campos
3. Dados aparecem no editor para ajustes

## Dados Pessoais

Preencha todos os campos obrigatorios:
- Nome completo, email, telefone
- Localidade, pais, nacionalidade
- Data de nascimento (opcional)
- LinkedIn, portfolio

## Carta de Conducao

1. Marque "Possui carta de conducao"
2. Selecione as categorias (A, A1, A2, AM, B, B1, BE, C, C1, CE, D, D1, DE)
3. Indique se tem viatura propria

## Disponibilidade

Ative as opcoes aplicaveis:
- Imediata
- Turnos
- Fins de semana
- Deslocacoes
- Mudanca de residencia

## Autorizacao de Trabalho

Indique o status: Sim / Nao / Nao Informado

## Ferramentas IA

- **Melhorar**: Reescreve com verbos de acao e metricas
- **Traduzir**: Para 7 idiomas com adaptacao cultural
- **Adaptar PT**: Vocabulario de Portugal (curriculo, telemovel, etc.)
- **Adaptar Cargo**: Reorganiza por relevancia do cargo alvo
- **ATS**: Otimiza para parsers automaticos
- **Gramatica**: Corrige erros ortograficos e gramaticais
- **Expandir**: Adiciona detalhes onde possivel
- **Resumir**: Encurta para 1 pagina
- **Melhorar Tudo**: Aplica todas as melhorias de uma vez

## Exportacao

- **PDF**: Formato profissional, secoes vazias ocultas
- **DOCX**: Editavel no Word, LibreOffice, Google Docs

## Regras Importantes

- IA NUNCA inventa empresas, cargos, datas ou resultados
- Apenas melhora a FORMA de escrever, nunca o CONTEUDO
- Informacoes faltantes ficam como "[A PREENCHER]"
- Preserva sempre: nomes, empresas, datas, URLs, emails
